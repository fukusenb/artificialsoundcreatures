# カエル合唱シミュレーター (Artificial Sound Creatures)

Felix Hess《Electronic Sound Creatures》の内部状態モデルと、合原一究のニホンアマガエル
逆相同期モデルを組み合わせた **2 層モデル** の合唱シミュレーター。実機ハードウェア
(マイク 1 個で混合音を聞く)の制約に合わせて設計している。

## 2 層モデル

**遅い層(Felix Hess): 「そもそも鳴くかどうか」= 単一の鳴きたさ `E ∈ [0,1]`(0〜100%)**
- `E` は自発的にじわじわ上昇し、カエルの声を聞くとジャンプする（興奮）。
- 環境音・人がいると下がり（抑制）、鳴いている間は疲れて下がる。
- `E` が 100% に達したら **CALLING** 開始。鳴いている間に `off_level` を下回ると **SILENT**（ヒステリシス）。
- → 人が近づくと静まり、去るとじわじわ鳴き戻る。1 匹の種火から合唱が点火する。
- 内部状態を「相対値の足し算＋閾値」から**単一の絶対値 E(%)** にしたので、画面の弧＝ E がそのまま読める。

**速い層(合原/逆相): 「鳴くとして、いつ鳴くか」**
- SILENT の間だけ、他個体の鳴きとそのタイミングを聞く。
- SILENT → CALLING に移る瞬間、最も大きく聞いた鳴きへ **+T/2(逆相)で位相を一度だけセット**。
- 鳴き始めたらタイミングは聞かず自走（固有周期）。以降は音がカエルか環境音かで内部状態を更新するだけ。
- 補正しないので固有周期の差で徐々にズレる → ゆるく揺らぐ交互合唱。

状態遷移:

```
SILENT  --(E>=100%; 最寄りの鳴きへ +T/2 一発セット / 種火なら固有位相)-->  CALLING
CALLING --(E<=off_level)-->  SILENT
```

## インタラクティブ版（ブラウザ・ドラッグ&ドロップ・推奨）

`interactive/index.html` をブラウザで開くだけ（インストール不要）。

```bash
open simulation/interactive/index.html
```

- 色付きの輪 = 鳴いている個体（弧＝位相）。灰色の輪 = 沈黙中（弧＝鳴きやすさ `D/閾値` の溜まり具合）。
- 個体・環境音を**ドラッグ**で移動、クリック選択、**Delete/Backspace** で削除。
- 「＋環境音/人」を個体の近くに置くと周りが静まる（＝人が田んぼに近づく体験）。
- 指標: 「逆相スコア」（鳴いているペアの逆相度）と「鳴いている割合」をライブ表示。
- スライダーは遅い層（baseline / threshold / 自発の溜まり / 興奮・抑制のゲインと減衰）と
  速い層（T / 個体差 / 検出遅延）に分かれる。「音を鳴らす」で WAV/MP3 を読み込むと実音で合唱。

## 主要パラメータ（`frog_chorus.Config`）

| 項目 | 層 | 意味 |
|---|---|---|
| `period_mean` / `period_spread` | 速い | 固有鳴き周期と個体差 |
| `latency` / `lat_comp` | 速い | AI 検出遅延と、+T/2 セット時の遅延補正 |
| `rise_rate` / `rise_spread` | 遅い | 鳴きたさ E の自発上昇速度 [1/s] / 個体差 |
| `exc_gain` | 遅い | カエル 1 声を聞いたときの E のジャンプ量 |
| `inh_gain` | 遅い | 環境音の単位音量あたり E を下げる速さ [1/s] |
| `fatigue` / `off_level` | 遅い | 発声中に E が下がる速さ / 停止レベル(ON は 100%) |
| `loudness_gate` / `ref_distance` | センシング | 近傍とみなす音量閾値 / 距離減衰の基準 |
| `noises` | 環境 | `[{'x','y','level','radius'}]`。`level` は `t` の関数でも可（人の出入り） |

## 実機への移植

`frog_chorus.simulate` の 1 個体ぶんの処理（内部状態の更新 → 状態遷移 → 発声 →
聞いた音の反映）が、そのまま XIAO ESP32S3 Sense 上の C++ ループに対応する。
`noise_at` / カエル検出は実機では DS-CNN の frog/non_frog 判定（+ 音量）に置き換わり、
frog→鳴きたさ E を+（興奮）、non_frog→ E を−（抑制）に駆動する。ここで固めたパラメータを移植の初期値にする。
